Region: us-east-1

About This Project

This website is hosted using Amazon S3 and delivered through Amazon CloudFront. It demonstrates how to configure a static website, apply public access permissions, and use a CDN for HTTPS and faster global content delivery.

What This Shows

  • Creating and configuring an S3 bucket
  • Enabling static website hosting
  • Setting bucket permissions for public access
  • Uploading and serving HTML content
  • Using CloudFront as a CDN
  • Serving the website over HTTPS

CloudFront Delivery

This site is delivered through Amazon CloudFront for HTTPS and faster global performance.
